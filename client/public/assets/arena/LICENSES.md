# Crownfall Arena asset licenses

Every 3D model in `models/` is **CC0 1.0 (public domain)**, converted with `tools/arena-assets.mjs`:

| Prefix | Source pack |
| --- | --- |
| `c-*` | Quaternius — Ultimate Animated Character Pack (quaternius.com) |
| `r-*` | Quaternius — RPG Characters |
| `m-big-*`, `m-blob-*`, `m-fly-*` | Quaternius — Ultimate Monsters |
| `a-*` | Quaternius — Ultimate Animated Animals |
| `k-*`, `p-*` | Kenney (kenney.nl) — Graveyard Kit, Mini Dungeon, Mini Arena, Castle Kit, Tower Defense Kit |

Arena decoration reuses Turbo Tumble's Kenney Nature Kit (`assets/environment/nature`, CC0).
Card portraits in `portraits/` are rendered from these models (`tools/arena-portraits.mjs`).
Card names and designs are original; gameplay roles follow the classic real-time card-battler genre.
