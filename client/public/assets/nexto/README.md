# Nexto

`nexto.bin` is the policy network of **Nexto**, the Rocket League bot trained with RLGym by Rolv-Arild Braaten
and the Necto team (https://github.com/Rolv-Arild/Necto, `rlbot-support/Nexto/nexto-model.pt`), exported to raw
float32 weights by `tools/nexto-export.py` and run by `client/src/rocket/sim/nexto.ts`.
